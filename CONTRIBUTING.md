# Contributing to Invoice Proof Registry

Thanks for your interest. This is a local-demo PoC; contributions that keep the scope and simplicity in mind are welcome.

## Running locally

1. From the repo root: `npm install`
2. Start the chain: `npx hardhat node` (leave it running)
3. Deploy: `npx hardhat run scripts/deploy.js --network localhost`
4. Serve the UI: `cd frontend-test && npx serve`
5. In MetaMask, add network RPC `http://127.0.0.1:8545`, Chain ID `31337`, and import a Hardhat dev account if needed.

See [README.md](README.md) for full quickstart and MetaMask setup.

## Reporting issues

- Open a GitHub issue with a clear title and description.
- Include: steps to reproduce, expected vs actual behaviour, Node/Hardhat versions if relevant.
- Do **not** post private keys or `.env` contents.

## Coding style

- **Solidity**: Follow the existing style (e.g. 0.8.24, OpenZeppelin patterns). Run Hardhat compile before submitting.
- **JavaScript / HTML**: Plain JS and HTML; no framework or build step. Prefer readable, consistent formatting; avoid unnecessary globals.
- **Commits**: Use clear, short commit messages (e.g. "Add README quickstart", "Fix role badge for ADMIN").

## Scope

- Keep the project a **local demo**: Hardhat node, chainId 31337, no production deployment or key handling in the repo.
- Do not commit `frontend-test/contract-info.json`; it is generated by the deploy script.
- Do not commit `.env` or any private keys; use Hardhat dev accounts or test wallets only.
